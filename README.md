# QuickBite — UX Case Study

QuickBite is a modern food delivery mobile application designed to improve usability, accessibility, and seamless ordering experiences for users. This project showcases the complete UX design process from research and wireframing to high-fidelity UI design and usability improvements.

---

## 📌 Project Goal

Design a user-friendly food delivery mobile app that helps users discover meals, place orders, complete checkout, and track deliveries in real time.

---

## 👨‍💻 My Role

UX Designer

---

## 🛠️ Tools Used

- Figma
- FigJam

---

## 🎯 Responsibilities

- User Research
- Wireframing
- Prototyping
- Accessibility Design
- Visual Design
- Usability Testing

---

## 🧠 Problem Statement

Many food delivery apps overwhelm users with cluttered layouts and confusing navigation. The goal of this project was to create a clean and intuitive experience that simplifies ordering and improves usability.

---

## 📱 Screens Included

### Home Screen
Focused on creating a clear visual hierarchy using banners, categories, search functionality, and featured content while maintaining accessibility and clean navigation.

### Menu Screen
Improved content organization, filtering, and intuitive menu browsing to help users quickly discover meals.

### Cart Screen
Designed a simplified cart experience with pricing transparency and easy quantity management.

### Checkout Screen
Created a seamless checkout flow focused on payment clarity, delivery details, and user trust.

---

## ♿ Accessibility Considerations

- High color contrast for readability
- Clear typography and spacing
- Large touch targets
- Consistent navigation patterns
- User-friendly mobile layouts

---

## 📚 Key Learnings

Through this project, I improved my understanding of:

- User-centered design
- Accessibility principles
- Visual hierarchy
- Mobile-first UX design
- Prototyping and usability testing
- Designing intuitive user flows

This case study also strengthened my skills in creating modern mobile interfaces using Figma.

---

## 🚀 Final Outcome

QuickBite successfully demonstrates a modern and accessible food delivery experience with intuitive navigation, seamless checkout, and user-focused interactions.
